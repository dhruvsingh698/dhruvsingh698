# Dhruv Digital Guide

A responsive, static educational website starter with original beginner-friendly guides.

## Files
- `index.html`: home page
- `articles.html`: article library
- Eight individual educational articles
- `about.html`, `contact.html`, `privacy.html`, `terms.html`, `disclaimer.html`
- `style.css`: responsive dark blue/purple theme
- `robots.txt` and `sitemap.xml`: replace the placeholder domain before use

## Before publishing
1. Replace the contact email placeholder in `contact.html` with an email address controlled by the site owner.
2. Review every article and policy page. Update anything that does not match your actual practices.
3. Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml` after a domain is selected.
4. Do not add ad scripts until the site owner has reviewed the advertising provider's rules and privacy requirements.
5. Do not claim guaranteed Adsterra approval. Approval is decided by Adsterra.
6. An adult parent/guardian should manage any account, contracts, identity checks and payment arrangements required for a minor.

## Preview
Open `index.html` in a browser. This site is static and does not need a build step.

## Hosting
Can be hosted as a static site. GitHub Pages, Cloudflare Pages and Netlify have different account terms, features and limitations; review the current terms with a parent/guardian before choosing a host.
